# 「点记 / TapTally」在 AstroBox 里显示 Logo + 应用名：结论与做法

## 一、先给结论（源码级已验证）

AstroBox 的安装队列条目，**图标和名称不是从 rpk 里读的**：

| 来源 | 队列显示的名字 | 队列显示的图标 |
| --- | --- | --- |
| 本地选文件（我们现在的方式） | **文件名**（`com.taptally.scoreboard.debug.1.0.0.rpk`） | 按扩展名的 **RPK 文件类型图标** |
| 资源社区（provider）条目 | 元数据里的 `name` | 元数据里的 `icon` 图片 |

证据（AstroBox 2.2.x 前端 bundle，路径 `C:\Users\linze\AppData\Roaming\moe.astralsight.astrobox\hotupdate\objects\fa8a9548fc448044c974bde561b23a3562c652710cb68c3fa901d2f37446e7d9`）：

- 队列条目创建：`{id, name, description, icon, type, status, progress, ..., action}`；
  从社区条目来：`name: o.item.name, icon: o.item.icon, type: o.item.restype`；
  从本地文件来：名字取 `basename`，图标走 `file-icon-<扩展名>`（abp/bin/face/mwz/rpk/crpack/unknown）。
- 全部前端 bundle 与 wasm 中 **搜不到 `logo.png` 字符串**，也没有解析 rpk 内 manifest 的 IPC 命令（只有 `device_get_file_type` / `device_get_file_size` / `device_get_watchface_id`）。⇒ 客户端**从不**读取 rpk 里的图标和名称。
- 你截图里的「水平仪」正是社区源条目：`index_v2.csv` 里 `LegacyItem7,水平仪,quick_app,leset0ng,lstReleaseForAstroBox,be562f9,logo.png,cover.png,...`，它的 logo 来自 `https://cdn.jsdelivr.net/gh/leset0ng/lstReleaseForAstroBox@be562f9/logo.png`（100×100，红球灰环），和 rpk 内的 `common/logo.png` 是同一张图。

结论：**想在自己的安装队列里也看到 logo + 名称，只能让「点记」成为资源社区条目**（或者改 AstroBox 客户端，不现实）。

## 三、要真正的「Logo + 应用名」：发布到资源社区

社区条目的形态已经摸清（以水平仪为例，仓库 `leset0ng/lstReleaseForAstroBox@be562f9`）：

```
仓库根目录/
  com.lst.level.release.1.0.0.rpk     ← 安装包
  logo.png                            ← 100×100 图标
  cover.png                           ← 1280×789 宣传图
  manifest.json                       ← 条目元数据
```

`manifest.json` 结构：

```json
{
  "item": { "name": "水平仪", "icon": "logo.png", "description": "...",
            "source_url": "...", "preview": ["cover.png"], "author": [{"name": "lst", "url": "..."}] },
  "downloads": { "n66": { "version": "1.0", "file_name": "com.lst.level.release.1.0.0.rpk" } }
}
```

`downloads` 的键是机型代号，小米手环9 = `n66`（同一机型在社区库里也写作 `xmb9`）。

然后往社区索引 `AstroBox-Repo/index_v2.csv` 追加一行：

```
id,name,restype,repo_owner,repo_name,repo_commit_hash,icon,cover,tags,device_vendors,devices,paid_type
com.taptally.scoreboard,点记,quick_app,<你的GitHub用户名>,taptally-band9,<commit短哈希>,logo-100.png,cover.png,实用工具;计分;比分;台球;乒乓;棋牌;对局,xiaomi,xmb9;n66,
```

### 落地步骤（需要你出 GitHub 账号）

1. **建仓库**：GitHub 新建公开仓库，例如 `taptally-band9`，把 `publish/` 下的 4 个文件传上去
   （`com.taptally.scoreboard.release.1.0.0.rpk`、`logo-100.png`、`cover.png`、`manifest.json`）。
2. **取 commit**：仓库首页复制提交的短哈希（7 位）。
3. **提索引**：给 `https://github.com/AstralSightStudios/AstroBox-Repo` 提 PR（或 issue），把上面那行 CSV 追加到 `index_v2.csv`；
   也可以在社区论坛 `https://www.bandbbs.cn/forums/astrobox/` 按「创作者投稿」流程提交。
4. **验证**：合并后打开 AstroBox →「资源社区 / 资源」→ 刷新，应能看到「点记」的圆形 logo 与名称；从那里下载安装，队列条目也会带 logo + 名称。

> 说明：`publish/` 里的 rpk 是**调试证书签名**的构建（官方工具链 development 模式，production 需要自备 `sign/private.pem` + `sign/certificate.pem`）。自己用没问题；如果要正式对外分发，建议先补齐签名证书再重新 `aiot release`。
