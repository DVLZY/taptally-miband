# 点记 TapTally · 真机验证清单（1.8.1）

> 适用：小米手环 9 / 9 NFC（192×490，胶囊屏）。其他机型见 [兼容设备.md](兼容设备.md)。
> 安装：AstroBox → 选 `点记-1.8.1.rpk` → 手环应用列表点「点记」。
> 包名 `com.taptally.scoreboard`，versionName **1.8.1** / versionCode **43**。
>
> 用法：按顺序做，把「实测」一列填上；不符预期的记下现场（截图或诊断读数），方便定位。

## 0. 安装与图标

| 编号 | 操作 | 期望结果 | 实测 |
| --- | --- | --- | --- |
| I1 | AstroBox 安装 `点记-1.8.1.rpk` | 显示「安装成功」，手环不重启 | |
| I2 | 手环应用列表找「点记」 | 圆形渐变图标（上绿下蓝、无分隔线，`0` 左上 / `9` 右下），大小与原生图标一致、**不压住应用名** | |

> 图标有系统缓存：装完没生效时，先删掉「点记」再装一次。

## 1. 基础记分

| 编号 | 操作 | 期望结果 | 实测 |

| V5 | 长按下半区 | 下方 −1，同样不补 +1 | |
| V6 | 该方为 0 时长按 | 停在 **0**，不出现负数 | |
| V7 | 连点 10 次上半区 | 一次不漏，累加到 10 | |

## 2. 中缝时间（1.8.0 新增）

| 编号 | 操作 | 期望结果 | 实测 |
| --- | --- | --- | --- |
| C1 | 打开应用看中缝 | 显示当前时间，小时在左、分钟在右，**无冒号**；小时十位与分钟个位明显更大 | |
| C2 | 与手机时间对比 | 小时与分钟一致（24 小时制；若显示 12 小时制或错时区，记录实际值） | |
| C3 | 停手等到下一分钟 | 时间在整分钟跳变，不闪、不跳秒 | |
| C4 | 看中缝上下 | 数字**没有被卡片裁掉**（时钟字号比中缝高，靠 `overflow: visible` 溢出显示） | |
| C5 | 上滑一次 | 时间消失，换成「再滑确认」；2.5 秒后时间回来 | |

> C1/C2 若完全不显示时间，说明设备上 `Date` 抛异常（代码会永久隐藏时钟），把这一情况记下来即可。

## 3. 上滑归零（1.8.1 全行程手势）

| 编号 | 操作 | 期望结果 | 实测 |
| --- | --- | --- | --- |
| G1 | 在屏幕中部**轻蹭**一下（竖直 40~60 像素） | **不触发**确认态（旧版会误触） | |
| G2 | 从屏幕**最下方**起手，划到**最上方**后松手 | 显示「再滑确认」，短震 1 次 | |
| G3 | 2.5 秒内做同样的全行程上滑 | 比分归 **0:0**，短震 2 次，列表多一条原比分 | |
| G4 | 上滑一次后停 3 秒 | 自动取消，不会误归零 | |
| G5 | 从底部起手但只划到屏幕中部就松手 | 不触发 | |
| G6 | 0:0 状态下全行程上滑两次 | 归零照旧，**不产生记录** | |
| G7 | 斜着划（横向漂移明显） | 不触发上滑 | |

> G1/G5/G7 若误判，长按中缝两次读出 `g<起手y>/<终点y>/<dy> dh<设计屏高>`，
> 把这行记下来 —— 阈值按比例定，手环 9 的标准是 起手 ≥760 / 终点 ≤466 / |dy| ≥294 / |dx| ≤144。

## 7. 记分列表

| 编号 | 操作 | 期望结果 | 实测 |
| --- | --- | --- | --- |
| L1 | 记分页**右→左划** | 进入「记录」页，标题居中完整 | |
| L2 | 看每一条 | 顺序 **序号 → 色条 → 比分**；色条颜色按胜负（绿=上方赢、蓝=下方赢、灰=平局） | |
| L3 | 连续存 3 局（5:3、2:0、7:4） | 显示 3 条，最新 `7:4` 在最上面 | |
| L4 | 存到第 6 局 | 只保留 **5 条**，最早一条被挤掉 | |
| L5 | **单击**某条 | 自动返回记分页，比分变成该条的比分 | |
| L6 | **长按**某条 | 该条被删除，序号重排 1、2、3… | |
| L7 | 删除后回记分页再存一局 | 被删的记录**不会复活** | |
| L8 | 列表页**左→右划** | 返回记分页，比分保持 | |

## 8. 诊断与兜底

| 编号 | 操作 | 期望结果 | 实测 |
| --- | --- | --- | --- |
| D1 | 长按记分页中缝（第 1 次） | 显示 `192x490 pill v1.8.1 r<n>` | |
| D2 | 紧接着再长按一次 | 切换到 `g<起手y>/<终点y>/<dy> dh1225`（做一次上滑后更有意义） | |
| D3 | 长按列表页标题「记录」 | 出现 `S89 F89 N5`，再长按收起 | |
| D4 | 长按列表页页脚 | 进入圆角试验页，底部显示 `192x490` 与 `screenShape` 真实值 | |

### 诊断行怎么读

| 串 | 含义 |
| --- | --- |
| `192x490 pill` | `device.getInfo()` 报的屏幕宽高与形状（`pill`=`pill-shaped`、`circ`=`circle`、`rect`） |
| `v1.8.1` / `r5` | 当前版本 / 内存里的记录条数 |
| `S89 F89 N5` | 偏好存储字符数 / 整份文件字符数 / 内存记录数。三个都在涨说明双通道都正常 |
| `g1100/200/-900` | 最近一次手势：起手 y / 终点 y / 竖直位移（设计像素） |
