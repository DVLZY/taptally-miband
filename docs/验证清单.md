## 本次（1.3.2）针对你报的 4 个问题的改动

| 你的问题 | 改法 |
| --- | --- |
| 1 「记录」标题靠左被圆角裁掉、右侧多一个计数 | 标题改为**居中**，**删除**右侧 `n/10` 计数 |
| 2 序号与比分字体太小、色条位置不对 | 行高从 92‰ 提到 **104‰**；比分字号 0.54→**0.66 倍行高**，序号 0.26→**0.40 倍行高**；色条移到**序号与比分之间** |
| 3 单击历史记录没还原比分 | 记分页**从列表返回时强制回读磁盘**（不再依赖页面间共享标志）；写入顺序改为「先写比分 → 再返回」 |
| 4 历史只保留 1 条 / 保留 5 条 | 数据层改为**内存缓存 + 纯文本落盘**（不再依赖 JSON 与异步回读）；上限 `MAX_RECORDS` **10 → 5** |

> 关于第 4 条的根因：旧版每次都「异步读 → 拼一条 → 写回」。真机上这次异步回读经常返回空，于是每次都写成「只有 1 条」。现在写入直接更新内存里的数组再落盘，读不到磁盘也不会把列表清掉。
