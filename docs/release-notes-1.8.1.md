# 点记 TapTally 1.8.1

对局计分快应用 · 小米手环 9 / 9 NFC

![点记](https://raw.githubusercontent.com/DVLZY/taptally-miband/main/media/cover.png)

## 这一版改了什么

### 上滑归零不再误触（1.8.1）

旧判定只看「竖直行程 > 90 设计像素」（≈ 屏高的 7%），拇指在屏幕上蹭一下就会进「再滑确认」。
现在要求**从屏幕下方划到上方的大半个行程**，四条同时满足才触发：

| 条件 | 阈值 | 手环 9 实际值 |
| --- | --- | --- |
| 起手位置 | ≥ 62% 屏高 | y ≥ 760 设计（304 物理） |
| 终点位置 | ≤ 38% 屏高 | y ≤ 466（186） |
| 竖直行程 | ≥ 24% 屏高 | ≥ 294（118） |
| 横向漂移 | ≤ 30% 屏宽，且竖向为主 | ≤ 144（58） |

顺手修掉一个浮点边界：`1225 × 0.24 = 294.00000000000006`，正好划到 294 会被判「不达标」，现在先取整再比较。

### 中缝显示时间（1.8.0）

上下卡片之间的窄缝从 4% 加宽到 13%，用来显示 `HH MM`：小时靠左、分钟靠右、不显示冒号，
小时十位与分钟个位用大字号（189）、另两位用小字号（122），四个数字各自按墨迹垂直居中。
显示「再滑确认」时时钟自动让位。

中缝变宽的代价是卡片变矮，两位数比分从 384 → 340，但仍做了圆角避让，不会被弧线切到。

### 更早的 1.7.x

- 卡片贴边 + 240px 圆角，与胶囊屏的弧线同心（不再有上下黑边）
- 字号按「数字半高处的可用宽度」迭代收敛，1~3 位数都不切字
- 图标改为圆形渐变（`0` 左上 / `9` 右下），占比 90%，不再压住应用名
- 列表条目行高 +20%，序号与页脚放大

## 安装

1. 下载下面的 `TapTally-1.8.1.rpk`
2. 打开 [AstroBox](https://astrobox.online)，BLE 连接手环
3. 「设备 → 安装队列」选择该文件

> **签名变更提醒**：从 1.7.0 起改用自签证书，与更早的调试证书包签名不同。
> 从 1.6.x 及更早升级时，先在手环上删掉「点记」再装；此后同证书版本可正常覆盖。

## 已知限制

- 列表保留最近 **5 局**，无撤销删除
- 单边比分上限 **999**
- 纯本地应用，不联网；NFC 版与普通版功能一致，未使用 NFC
- 中缝时间依赖运行时 `Date`，若设备返回异常则不显示时间
