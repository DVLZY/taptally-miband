# 兼容设备梳理（点记 / TapTally）

> 结论先行：**1.2.0 起「点记」按屏幕宽高比自适应**，理论上覆盖全部「支持快应用的小米穿戴设备」；
> 但**只在小米手环 9（含 NFC）上做过真机验证**，其余机型是推算结论，需要真机确认后才能标为「已验证」。

## 一、为什么能跨设备：自适应原理

快应用用 `designWidth: 480` 做设计稿映射，**CSS px 会按屏幕宽度等比缩放**，所以：

- `width: 100%` / `height: 48%` 这类百分比布局在任何比例屏幕上天然成立；
- 但**固定 px 的字号**会随屏幕比例失真（例：9 Pro 宽 336、高 480，卡片只有 315 设计 px 高，而旧版 2 位数字是 350px → 直接溢出）。

1.2.0 的做法：运行时用 `@system.device.getInfo()` 拿真实 `screenWidth / screenHeight / screenShape`，
反推「设计高度」`dh = 480 × 屏高 / 屏宽`，再按 `dh` 计算卡片高度、圆角、内边距、字号：

```
pad      = 圆屏 ? 480×0.1465(=70) : 14      // 圆屏要缩进到内接矩形里，否则四角被裁
gap      = dh × 4%
cardH    = (dh − 2×pad − gap) / 2
cardW    = 480 − 2×pad
radius   = 圆屏 ? cardH/2（胶囊形，避免边角被圆形边框切掉）: 52
fontsize = min( cardW / (0.60 × 位数) × 0.96 , cardH × 0.74 , 430 )
```

列表页同理：条目高度 `itemH = clamp(dh×7.8%, 56, 120)`，序号/比分/时间/色条宽高全部由 `itemH` 推导，
圆屏左右各缩进 70 设计 px，保证不被圆形边框裁切。

## 三、明确不支持的设备

| 设备 | 原因 |
| --- | --- |
| 小米手环 7 / 7 Pro、手环 8 / 8 NFC | 平台不支持第三方快应用安装（AstroBox 设备表也没有这些机型的快应用通道） |
| 小米手环 7 及更早 | 同上，且系统是自有 RTOS 界面，非 Vela 快应用框架 |
| 手机（Android/iOS） | manifest `deviceTypeList` 只声明 `watch`；且本应用的交互（单击/长按/上下滑）是为手环小屏设计的，装到手机上体验也不对 |

## 四、影响兼容性的三个 manifest 字段

| 字段 | 当前值 | 说明 |
| --- | --- | --- |
| `deviceTypeList` | `["watch"]` | 只声明手表类；手环也走 `watch` 类，不需要改成 `band` |
| `minPlatformVersion` | `1200` | 平台版本下限。**老机型（如 Watch S3 早期固件）装不上时**，可降到 `1100` 或 `1000` 再试；本应用只用了 store/brightness/vibrator/file/device/router，这些 API 在 1000 就存在 |
| `features` | router / configuration / vibrator / brightness / storage / file / device | 少声明任何一项，对应 API 调用会被拒绝 |

## 五、要扩大支持范围，还需要做什么

1. **真机验证**（优先级从高到低）：手环 10 → 手环 9 Pro/10 Pro（曾是溢出机型）→ 手表 S4/S5（圆屏）。
   验证只需要截图 + 确认三点：数字不溢出、卡片四角不被裁、列表能滚动。
2. **补齐设备像素信息**：在手环 11、vivo GT 2 上跑一次 `@system.device.getInfo()`，
   把 `screenWidth / screenHeight / screenShape / platformVersionCode` 记进本文件。
   （临时办法：把这几个值显示在记分页中间横条上，装一次就能读出来。）
3. **放宽 `minPlatformVersion`**：等确认目标机型的平台版本后决定，宁可低不要高。
4. **分发端扩列**：发布到资源社区时，`manifest_v2.json` 的 `downloads` 目前只写了 `xmb9`。
   多机型支持（且验证过）之后，可以加 `xmb10` / `xmb9p` / `xmws4` 等键，指向同一个 rpk。

## 六、当前分发状态

- 已发布机型键：`downloads.xmb9`（小米手环 9 / 9 NFC 共用同一代号）
- 未验证机型**刻意不加键**，避免用户装上后布局错乱却没处反馈。
